# Юнит-тесты — §11.1 ТЗ

Маркер: `@pytest.mark.unit`.

Обязательный минимум (таблица §11.1). Каждая строка — отдельный тест:

| Модуль | Что проверяется |
| --- | --- |
| `normalize` | `\xa0`, форматы чисел `1 234,56`/`1234.56`, даты с временем и без, наследование даты вниз |
| `normalize` | корр. счёт берётся из **G** для дебета и из **E** для кредита |
| `ingest` | локация блоков во всех четырёх вариантах §3.3 |
| `ingest` | fallback по времени и его верификация (принятие **и** отказ) |
| `validate` | V1–V3 срабатывают на заведомо битых данных |
| `classify` | регулярка служебных не отбрасывает «Правосуд Дмитрий» |
| `reversals` | пара гасится; сторно с реальной выдачей **НЕ** гасится |
| `timing` | `collapseTiming` на синтетике: сдвиг +1 → остаток 0 |
| `timing` | `lagScore` находит известный лаг |
| `timing` | календарная агрегация Пт+Сб+Вс = Пн |
| `localize` | правило единственной проводки |
| `localize` | subset-sum: уникальное решение принимается |
| `localize` | subset-sum: N=80 → отказ (гейт) |
| `localize` | subset-sum: два решения → `AMBIGUOUS` |
| `balance` | фильтр полноты выемки отсекает частичные |
| `balance` | инвариант неотрицательности датирует первый минус |
| `decompose` | раскладка сходится при T=0 и при T≠0 |
| `report/excel` | текст с ведущим `=` не становится формулой |

Инварианты свёртки (§5.7.2) дополнительно покрываются property-based тестами на
`hypothesis`: сумма погашенного и остатка обязана равняться исходной сумме
разниц при любом входном ряде.
