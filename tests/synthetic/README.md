# Синтетические кейсы — §11.2 ТЗ

Маркер: `@pytest.mark.synthetic`.

Генератор синтетических касс с внедрёнными дефектами **известной величины и
позиции**. Каждый дефект из таксономии §8 должен иметь генератор и тест
«внедрили → нашли ровно это».

## Обязательные негативные кейсы

Они важнее позитивных: инструмент, который всегда что-то находит, бесполезен.

1. **Чистая касса без дефектов** → ноль находок `severity=ОШИБКА`, раскладка
   сходится, сальдо = T.
2. **Касса только с таймингом** → ноль находок, остаток свёртки 0.
3. **Касса с 80 чеками в проблемном дне** → **отказ локализации**, а не
   догадка (§7.4: локализация ниже дневного агрегата продаж запрещена
   независимо от гейтов).

Кейс 3 — прямая проверка принципа §0.3. Тест обязан утверждать, что статус
равен `REFUSED_BELOW_Z_REPORT`, и что в объяснении названа причина отказа и
запрошен Z-отчёт за конкретную дату.
