подхватываются регрессией автоматически; переменная `CASHFORENSICS_FIXTURES`

## Как они обезличены

`tests/regression/anonymize.py`. ФИО в колонках «Кому выдано» (блок РКО) и
«От кого принято» (блок ПКО) заменены устойчивыми псевдонимами
`Получатель NNNNN`. Сохранены ровно три свойства, от которых зависит результат:

1. совпадение с `patterns.central_cash` («ентральн») — §3.6 отличает по нему
   инкассацию от возврата;
2. совпадение с `patterns.service_recipients` — §3.6 отделяет служебные выдачи;
3. тождество и различие имён — §8.1 группирует повторы по паре
   «получатель + сумма».

Значения обоих первых классов на этих кассах — организационные единицы, не
люди («Центральная касса РПВЗ», «СУД ПВЗ Солигорск», «АРХИВ ПВЗ Солигорск
PAX 119011650», «Финконтроль»), и перенесены дословно. Обобщённая подпись
«Клиент» тоже: за ней нет конкретного лица.

**Длину строки и коллизии Jaro-Winkler сохранять не требуется** — прежняя
редакция этого файла требовала, ссылаясь на §5.9.2, но проход 2 (венгерский
алгоритм) там назван опциональным и в конвейере не включён: `name_similarity`
вызывается только из `hungarian_match`, а тот не вызывается ниоткуда.
Единственное активное сопоставление — `greedy_match` по точной сумме в окне
`DATE_WIN`, имена ему не нужны.

## Чем доказано, что обезличивание ничего не сломало

* **Снапшоты §11.3 совпали без обновления** — все девять. Это и есть проверка:
  разошёлся бы хоть один, значит замена задела не только имена.
* **2 408 976 ячеек сверены с оригиналами**: вне колонок имён — ноль отличий,
  внутри — ноль незаменённых личных значений.

Ловушка, которую это поймало: первая версия заменила сам заголовок «Кому
выдано» псевдонимом. §3.3 ищет блоки опер-лога **по заголовкам**, блок
перестал находиться, и на `Кса_норма` обороты лога обнулились, а обе категории
стали неверифицируемыми — при том что число замен выглядело правдоподобно.
Поэтому скрипт отказывается работать, если заголовок колонки не найден, а не
заменяет вслепую.

## Если добавляете новую кассу

```sh
uv run python tests/regression/anonymize.py <каталог-с-оригиналами> tests/regression/fixtures
```

Оригиналы с ФИО в репозиторий не кладутся ни при каких условиях: `.gitignore`
отсекает `*.xlsx`, и обезличенные файлы добавлены осознанно через `git add -f`.
