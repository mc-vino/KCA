# Фикстуры регрессии — §11.3 ТЗ

Сюда кладутся восемь калибровочных выгрузок `.xlsx` и эталонные JSON-снимки.

**Персональные данные.** Блок РКО содержит ФИО получателей (см. §3.6 ТЗ, кейс
«Правосуд Дмитрий»). Файлы не коммитятся в открытый репозиторий без
обезличивания: ФИО заменяются на устойчивые псевдонимы так, чтобы сохранялись
длина строки и коллизии, от которых зависит Jaro-Winkler (§5.9.2).

Ожидаемые имена файлов:

```
Кса_с_отклонением.xlsx
Кса_норма.xlsx
Максиму_касса_2.xlsx
Максиму_3.xlsx
Щучин.xlsx
горновых.xlsx
PAX_119049688.xlsx
PAX_119011650.xlsx
PAX_119023531.xlsx
```

При отсутствии файла соответствующий тест пропускается с указанием причины
(`pytest.skip`), но **не** заменяется синтетикой: подмена эталона синтетикой
превращает регрессию в самоподтверждающийся тест.
