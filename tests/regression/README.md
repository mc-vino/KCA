## Дополнительные проверки, которые обязана делать регрессия

* **V1–V3 проходят на всех восьми** (§13.1).
* **`|unresolved| < EPS_TIE` на всех восьми** (§13.2).
* **Повторный прогон даёт побитово идентичный JSON** (§13.5) — тест запускает
  конвейер дважды и сравнивает байты, а не разобранный объект.
* **Остатки свёртки совпадают с таблицей §5.7.4** — критерий готовности
  этапа 1 (§14).

## Фикстуры

Сами `.xlsx` лежат в `fixtures/`. Это выгрузки с персональными данными
клиентов (ФИО получателей в блоке РКО): в репозиторий их класть нельзя без
обезличивания. Если фикстур нет на диске, регрессионные тесты обязаны
**пропускаться с явной причиной**, а не падать и не подменяться синтетикой.
