cashforensics

Форензик-анализ операционной кассы ПВЗ по выгрузке 1С «Карточка счёта 50.2». Отвечает на один вопрос: из-за каких конкретно документов сальдо на конец периода отличается от целевого — и раскладывает отклонение так, чтобы раскладка сходилась без остатка.

Файл не покидает ваш браузер. Анализ идёт локально: Python-пакет cashforensics исполняется прямо на этой странице через Pyodide (WebAssembly). Ни выгрузка, ни отчёты никуда не отправляются — это обязательное свойство, потому что блок РКО содержит ФИО получателей.
