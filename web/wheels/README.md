# Колёса для браузерной сборки

Pyodide содержит `numpy`, `scipy`, `pydantic`, `pyyaml`; `openpyxl` и
`et_xmlfile` ставятся из PyPI как чистый Python. Не хватает только `ruptures` —
он бинарный, и wasm-колеса для него нет ни на PyPI, ни в дистрибутиве Pyodide.

## `ruptures-1.1.10+purepy-py3-none-any.whl`

Собрано из официального sdist `ruptures` 1.1.10. Изменение ровно одно: два
C-расширения заменены заглушками, которые при вызове бросают
`NotImplementedError`.

| Модуль | Кому нужен | В §5.8.4 |
| --- | --- | --- |
| `detection/_detection/ekcpd` | `KernelCPD` | не используется |
| `utils/_utils/convert_path_matrix` | `KernelCPD` | не используется |

`Pelt` — единственный детектор, который §5.8.4 применяет — не импортирует ни
одного из них: ему нужны `math`, `ruptures.costs`, `ruptures.base`,
`ruptures.exceptions` и `sanity_check`. Без заглушек падает не он, а
`import ruptures`: пакет тянет `KernelCPD` в своём `__init__`.

Заглушка бросает ошибку, а не возвращает правдоподобное число — §0.3.

### Чем доказано, что подмена ничего не изменила

Прогон §5.8.4 на всех девяти калибровочных кассах §11.3 обоими сборками:

* **44 точки разладки** — совпали все, до индекса и до границ окна;
* **36 окон сдвига** — совпали все, до сумм потоков и доминирующей категории.

Локальная версия `+purepy` по PEP 440 сделана намеренно: артефакт заведомо не
upstream, и это видно в `pip list` и в логе установки.

### Пересборка

```sh
curl -sLO <sdist ruptures 1.1.10>
# заменить два модуля заглушками, убрать ext_modules из setup.py,
# проставить version = 1.1.10+purepy в setup.cfg
uv build --wheel
```

После пересборки **обязательно** сверить §5.8.4 с обычной сборкой на
калибровочных кассах: расхождение хоть в одной точке разладки означает, что
заглушка задела рабочий код.
